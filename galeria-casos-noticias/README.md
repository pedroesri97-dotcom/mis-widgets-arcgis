# Widget: Galería de Casos y Noticias (Gemelo Digital)

Widget personalizado para **ArcGIS Experience Builder (1.17)** diseñado bajo el **Sistema de Diseño Calcite de Esri**.

## Características
1. **Carrusel continuo / Bucle de Noticias**:
   - Tarjetas fotográficas con degradado oscuro de alta legibilidad.
   - Etiquetas de número de caso (`01 / 06`) y categoría temática (`GEMELO DIGITAL`, `CAPACIDAD`, `INFRAESTRUCTURA`, etc.).
   - Títulos y etiquetas de palabras clave.
   - Auto-scroll configurable con pausa automática al pasar el cursor (`Hover para pausar`).
   - Controles de navegación manual izquierda / derecha.
   - Vinculación interactiva a ventanas emergentes (Dialogs) nativas de Experience Builder o URLs externas.
2. **Cabecera Institucional**:
   - Subtítulo oficial (`OBSERVATORIO · GALERÍA DE CASOS`) con barra divisoria sutil.
   - Título con resalte de color institucional (`Territorios que ya deciden con datos.`).
3. **Banner Institucional de Ecosistema**:
   - Tarjeta dedicada para entidades: *"¿Tu entidad quiere sumarse al ecosistema? Conoce los acuerdos de intercambio de datos y los niveles de servicio disponibles."*
   - Botón Calcite *"Solicitar acceso"* con apertura de diálogos o enlaces.
4. **Diseño 100% Calcite**:
   - Tipografía oficial `"Avenir Next", "Helvetica Neue", "Segoe UI", Arial, sans-serif`.
   - Paleta Calcite Dark Slate (`#0d141d`, `#0f1824`, `#131d2a`, `#1e293b`, `#007ac2`).
   - Cero cursiva y densidad compacta para ingeniería GIS.
